# 🎮 롤 내전 풀스택 매치메이커 & MMR 랭킹판 대시보드

이 프로젝트는 디스코드 봇과 실시간 웹 대시보드가 결합된 **리그 오브 레전드 내전 전용 풀스택 애플리케이션**입니다. 
디스코드에서 참가자 모집 및 팀 배정을 진행하면, 그 현황이 **실시간 웹 대시보드에 WebSockets(소켓)으로 연동**되며, 내전 경기 종료 후 승리 결과를 웹에서 보고하면 자동으로 **MMR과 전적 랭킹이 실시간 업데이트**됩니다.

---

## 🛠️ 주요 기능

1. **디스코드 실시간 연동**:
   * 디스코드에서 `/내전모집` 및 참가 버튼 클릭 시, 웹페이지의 1~10번 대기열 카드가 새로고침 없이 **실시간으로 동적 갱신(소켓)**됩니다.
2. **티어 반영 밸런스 팀 매칭**:
   * 디스코드에서 `🎲 랜덤 팀 배정` 버튼을 클릭하면, 등록된 소환사들의 티어 가중치(MMR)를 계산하여 두 팀의 실력 차이가 최소화되는 **최적의 밸런스 대진표**를 자동으로 생성합니다.
   * 팀 배정 완료 시 디스코드 임베드에 1팀(블루) / 2팀(레드) 명단이 출력되고, 구글 시트의 드래프트 판에도 플레이어 이름이 자동으로 기입됩니다.
3. **통합 전적 및 MMR 데이터베이스**:
   * 가벼운 **SQLite** 데이터베이스를 내장하고 있어, 봇 재시작 시에도 대기열 및 전적 정보가 온전히 유지됩니다. (Prisma ORM을 탑재하여 향후 MySQL로 즉시 마이그레이션 가능)
4. **소환사 티어 정보 자동 연동**:
   * 구글 시트의 기존 `티어 정리` 탭에서 소환사 정보(이름, 나이, 닉네임, 티어, 라인)를 단 한 번의 명령어로 DB에 통째로 긁어오는 **초기 이관 스크립트**가 내장되어 있습니다.
   * 디스코드 닉네임에서 앞의 3글자(실명)를 추출해 DB와 자동 매칭하고, 봇을 처음 이용하는 유저의 디스코드 ID를 기존 DB 기록에 자동으로 묶어주는 **자가 치유(Self-healing) 바인딩 기능**을 제공합니다.
5. **웹 기반 승리 보고 시스템**:
   * 대진표가 구성되면 웹 대시보드에 승리 보고 패널이 활성화되며, 지정한 관리자 비밀번호를 통해 `블루 승리` 또는 `레드 승리`를 선택하여 제출하면 참여자 10명의 MMR(+15 / -15점)과 승/패 횟수가 즉시 업데이트됩니다.

---

## 📂 프로젝트 구조

* `/server`: 백엔드 Express 서버, SQLite DB (Prisma), Socket.io, 디스코드 봇 클라이언트
* `/client`: 프론트엔드 Vite + React SPA (Outfit/Inter 폰트 기반 Hextech 다크 모드 프리미엄 UI)

## 🚀 설치 및 세팅 방법 (24시간 컴퓨터 기준)

### 1단계: 프로젝트 패키지 설치
각각 백엔드와 프론트엔드의 라이브러리를 설치합니다.
```bash
# 백엔드 의존성 설치
npm --prefix server install

# 프론트엔드 의존성 설치
npm --prefix client install
```

### 2단계: 환경 변수 설정
프로젝트 루트 폴더(`c:\DiscordGoogleBot`)에 있는 `.env` 파일에 다음 항목을 설정합니다:
```env
# 디스코드 설정
DISCORD_TOKEN=your_discord_bot_token_here
CLIENT_ID=your_discord_client_id_here
GUILD_ID=your_discord_guild_id_here (즉시 명령어를 연동할 디스코드 서버 ID)

# 구글 시트 설정 (초기 데이터 이관용)
SPREADSHEET_ID=your_google_spreadsheet_id_here
SHEET_NAME=시트1

# 웹 대시보드 승리 보고 관리자 비밀번호
ADMIN_PASSWORD=admin123
```
* 루트 폴더에 구글 서비스 계정 키 파일인 **`credentials.json`**이 존재하는지 다시 한번 확인해 주세요.

### 3단계: 로컬 DB 설정 및 마이그레이션
Prisma 명령어를 실행하여 로컬 SQLite 데이터베이스 파일(`dev.db`)을 생성하고 연동합니다:
```bash
npm --prefix server run db:migrate
```

### 4단계: 기존 구글 시트의 소환사 데이터 DB로 이관하기
기존 `티어 정리` 구글 시트에 있는 플레이어 명단을 로컬 데이터베이스로 긁어옵니다:
```bash
npm --prefix server run import
```
* **성공 시**: `Successfully imported/updated 46 players in the SQLite database.` 메시지가 표시되며 로컬 DB에 플레이어 정보와 라인 가중치가 저장됩니다.

### 5단계: 프론트엔드 React 빌드
프론트엔드 코드를 빌드하여 백엔드 서버의 정적 폴더(`server/public`)로 컴파일합니다. (단일 프로세스로 가동하기 위함)
```bash
npm --prefix client run build
```

## 🏃 실행 및 테스트

명령어를 디스코드 서버에 동기화한 후, 24시간 가동 서버를 실행합니다.

### 1. 디스코드 슬래시 명령어 배포 (최초 1회 필수)
```bash
node deploy-commands.js
```

### 2. 통합 서버 기동 (24시간 켜둘 명령)
```bash
npm --prefix server start
```
* PM2를 사용해 무중단 가동하는 경우:
  ```bash
  pm2 start server/server.js --name "lol-fullstack-app"
  ```

## 🖥️ 확인 방법
* **웹사이트 주소**: 24시간 켜두는 컴퓨터의 웹 브라우저에서 **`http://localhost:3000`**에 접속합니다. (서버와 동일한 대역의 공유기 내 다른 기기라면 `http://[컴퓨터IP]:3000`으로 접속 가능)
* **연동 테스트**:
  1. 디스코드 채널에서 `/내전모집`을 칩니다.
  2. 웹 브라우저 대기열 화면을 켜둔 채로, 디스코드에서 `✋ 손들기` 버튼을 눌러봅니다.
  3. **웹 화면의 카드에 내 이름과 선호 라인 정보(O/X), 티어 정보가 실시간으로 채워지는지** 확인합니다!
  4. 10명이 차면 `🎲 랜덤 팀 배정` 버튼을 눌러 블루/레드 팀이 정상 배정되는지 보고, 웹페이지의 **대진 결과 보고** 탭에서 승리 보고 시 MMR 랭킹판에 전적이 실시간 업데이트되는지 확인합니다!
